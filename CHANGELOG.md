# Changelog

All notable changes to ADB Commander will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Dual-pane local and Android file browsing.
- Multiple ADB device picker.
- Bidirectional file transfers and a streaming tar fast path.
- Non-destructive incremental updates with read-only analysis, a confirmation
  summary, and warnings for large or broad folder scopes.
- Local file opening and contextual Finder/device transfer actions.
- Localized hover labels for icon-only controls.
- Independent sortable columns in both file panels.
- Lazy image and video thumbnails.
- English-only interface.
- Norton Commander-style keyboard navigation with a distinct file cursor,
  marking, range selection, folder history, type-to-jump and contextual
  function-key commands.
- Copy review with size and free-space checks plus replace/skip conflict
  decisions.
- Transfer cancellation, retry, detailed errors, current file, speed and ETA.
- Persistent panel folders, selected device, view, hidden-file and sort
  preferences.
- Safe demo mode with fictional data.
- macOS packaging configuration.
